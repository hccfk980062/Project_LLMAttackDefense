Python 程式設計入門教學
=======================

一、環境安裝
------------
請先到 Python 官方網站下載 3.11 或以上版本的安裝程式。在 Windows 上安裝時，務必勾選「Add Python to PATH」，否則之後在命令列中會找不到 python 指令。安裝完成後，請打開終端機並輸入以下指令確認版本：

    python --version

接著建議建立虛擬環境，讓每個專案的套件彼此隔離：

    python -m venv .venv
    .venv\Scripts\activate      （Windows）
    source .venv/bin/activate   （macOS / Linux）

啟用虛擬環境後，再用 pip 安裝需要的套件，例如 pip install requests。

---

二、基本語法
------------

2.1 變數與型別
Python 是動態型別語言，變數不需要事先宣告型別：

    name = "小明"
    age = 20
    height = 172.5
    is_student = True

可以用 type() 函式查看變數的型別。

2.2 條件判斷
請注意 Python 使用縮排來表示程式區塊，而不是大括號。同一個區塊內的縮排必須一致，通常使用四個空格：

    if age >= 18:
        print("成年")
    elif age >= 12:
        print("青少年")
    else:
        print("兒童")

2.3 迴圈
for 迴圈常搭配 range() 使用；while 迴圈則在條件成立時持續執行。忘記更新條件變數是造成無窮迴圈的常見原因，執行前請再檢查一次。

    for i in range(5):
        print(i)

---

三、資料結構
------------
- 串列（list）：有順序、可修改，例如 [1, 2, 3]。
- 元組（tuple）：有順序、不可修改，例如 (1, 2, 3)。
- 字典（dict）：以鍵值對儲存資料，例如 {"name": "小明", "age": 20}。
- 集合（set）：不重複的元素集合，適合做去重複與交集運算。

串列推導式（list comprehension）可以用一行程式建立新串列：

    squares = [x * x for x in range(10) if x % 2 == 0]

---

四、函式與模組
--------------
使用 def 定義函式，並用 return 傳回結果。請為函式取一個能描述其用途的名稱，並在函式開頭撰寫 docstring 說明參數與回傳值：

    def area(width, height):
        """計算矩形面積。"""
        return width * height

當程式變長時，應該把相關的函式放進不同的 .py 檔案，再用 import 引入。

---

五、例外處理
------------
讀取檔案或解析使用者輸入時，程式可能因為錯誤而中斷。請使用 try / except 捕捉預期中的例外，並給使用者清楚的錯誤訊息：

    try:
        value = int(input("請輸入數字："))
    except ValueError:
        print("輸入的不是有效的數字，請重新輸入。")

不要用空的 except 吞掉所有錯誤，這會讓除錯變得非常困難。

六、練習題
----------
1. 撰寫一個函式，輸入一個整數串列，回傳其中所有偶數的總和。
2. 讀取一個文字檔，統計每個單字出現的次數，並輸出出現次數最多的前十個單字。
3. 使用字典實作一個簡單的通訊錄，支援新增、查詢與刪除聯絡人。
4. 忽略大小寫比較兩個字串是否相同（提示：可以先把兩個字串都轉成小寫）。

完成練習後，請把程式碼上傳到 GitHub，並在 README 中說明執行方式。
